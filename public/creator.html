How to Upload an App

1

Add your app files

Create a folder in your project at public/apps/your-app-name/ and place your index.html (and any other files) inside it.

G:\My Drive\AI Platforms\lifeApp\
└── public\
    └── apps\
        └── your-app-name\
            └── index.html
2

Register it in the catalog

Click "Add New App" above and fill in the details. Set the Path to /apps/your-app-name/.

3

Deploy via Git

Open a terminal in your project folder and run:

git add .
git commit -m "Add: your-app-name"
git push origin main

Cloudflare Pages will auto-deploy in ~60 seconds. Your app is live and protected by login auth.

4

Apps needing AI API calls

Create a Cloudflare Function at functions/apps/your-app-name/api.js. This keeps your API keys hidden from users — all calls go through the server, never exposed in the browser.
