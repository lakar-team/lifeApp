PDF → DXF Vectorizer / scanned engineering drawings, server-side

Upload a scanned drawing (PDF or PNG/JPG). The server traces every line, arc, circle and dot at the scan's native resolution and returns a millimetre-accurate DXF plus a visual verification overlay. Large scans take a few minutes — the progress below shows real pipeline counters, not an animation.

Backend server

The conversion engine runs as a separate Python service (this static site can't do minutes of number-crunching). Enter its URL once — it's remembered in this browser. Running it yourself: docker run -p 8000:8000 <image> or uvicorn app.main:app from backend/pdf-to-dxf/ in the repo, then use http://localhost:8000.
